# Изменения

## 0.3.0 — 20 октября 2026

Дополнение 21 октября: отдельный `yandex_login.py` открывает сайт Яндекса, после подтверждения получает токен и сохраняет `.env` без регистрации приложения пользователем. Клиент автоматически читает файл. Добавлены проверка токена, сохранение остальных настроек, альтернативный OAuth-режим и Windows-команды запуска без зависимости от PATH.

- Официальный OAuth-вход по коду устройства: `auth login`, ожидание, отказ, истечение кода.
- Хранение токена в защищённом хранилище ОС; `auth import/status/refresh/logout`.
- `get_token()` для Python и автоматическое использование сохранённого токена в CLI.
- `auth check`: независимые проверки Яндекс ID и чтения умного дома без вывода личных данных.
- `--anonymous` игнорирует окружение и хранилище; токен печатается только явной командой `auth token --show`.
- Тесты изолированы от настоящего хранилища и переменных с учётными данными.

## 0.2.0 — 20 октября 2026

- Общий асинхронный транспорт вместо трёх копий клиента и отдельной потоковой реализации.
- Запросы регистрируются до отправки: исправлена потеря мгновенного ответа.
- Закрытие WebSocket завершает ожидающие запросы также при штатном завершении итератора.
- Отмена, ошибки и таймауты освобождают запросы и аудиопотоки; размер аудио ограничен.
- Добавлена проверка структуры JSON, идентификаторов потоков и входных параметров.
- Токены передаются через скрытый ввод или окружение, не выводятся в диагностику.
- PyAudio загружается только для микрофона. В ASR исправлены единицы размера аудиоблока, обработка запоздалых результатов, остановка и освобождение драйвера.
- Сохранены четыре исходных имени скриптов; добавлены пакет, CLI, тесты и CI.
- Озвучивание в CLI выполняется через текстовый ответ и отдельный TTS: встроенный аудиопоток в анонимной проверке не пришёл.
- README, исследовательское уведомление и описание происхождения кода оформлены заново.

### Переход со старого API

`YandexAliceClient.send_text()` сохраняет аргумент `is_tts_response` и ключи `response_payload`, `audio`, `full_directives`. Ошибки транспорта и таймауты теперь возбуждают исключения вместо возвращения предположений о неверном токене.

Синхронный `YandexAliceClientPython` сохраняет `connect`, `synchronize_state`, `send_text(text, is_tts=False)` и `close`. Его `send_text` возвращает прежние ключи `response` и `audio`. Всегда закрывайте адаптер или используйте `with`.

Внутренний `UniproxyPython` и внутренние типы `ActiveRequest`/`AudioStream` заменены общей реализацией и больше не являются точками импорта. Глобальные `PRESET_OAUTH_TOKEN`, `USER_OAUTH_TOKEN`, `ASR_SERVICE_KEY` и `asr_active` удалены. Для ASR используйте окружение и настройки экземпляра клиента. Отдельная зависимость `websocket-client` больше не требуется.

Минимальная версия Python повышена до 3.11.
