# Проверка LS Client

Я использую автоматические тесты для транспорта, авторизации, CLI и голосового режима. Матрица GitHub Actions включает Windows и Linux с Python 3.11, 3.12 и 3.14. Текущий результат доступен на [странице Actions](https://github.com/Iversat/LS-Client/actions).

## Автоматические проверки

```bash
python -m pip install -e ".[dev]"
python -m pytest -q
python -m ruff check .
python -m ruff format --check .
python -m pip check
python -m build
```

Для проверок с обработкой аудио установите `.[dev,voice]`. Без голосовых зависимостей соответствующие тесты пропускаются.

Тесты покрывают сопоставление ответов с запросами, перенос сессии, бинарные аудиопотоки, таймауты, отмену, закрытие соединения, OAuth и Passport, чтение `.env`, сохранение токенов, оба триггера и выбор языка. Сетевые ответы и устройства подменяются; обычный запуск тестов не обращается к аккаунту и не включает микрофон.

## Текст и TTS с реальным сервисом

```bash
python -m alice_client chat --anonymous --text "Привет"
python -m alice_client chat --text "Привет"
python -m alice_client tts "Проверка синтеза речи." --play
python scripts/verify_services.py --output responses/verification
```

Последняя команда проверяет одиночный запрос, последовательность реплик и TTS с токеном и без него. Отчёт и аудио сохраняются локально в указанной папке. Для сессии можно использовать игру «Города»: начать игру, назвать город, затем завершить её словом «хватит».

## Распознавание и голос

```bash
python -m alice_client asr --file russian.wav
python -m alice_client asr --file english.wav
python -m alice_client asr --duration 10
python -m alice_client voice --duration 30
```

В одном запуске `auto` произнесите «Алиса, привет», затем “Alice, hello”. Проверьте распознанный текст, срабатывание обоих триггеров и слышимость ответа. Для повторяемого сценария используйте файл с паузами между репликами: `voice --file sample.wav --no-play`.

Я разделяю проверку распознавания, ответа сервиса и воспроизведения: корректный текст ASR не гарантирует правильность ответа Алисы или поддержку английского диалога. Для воспроизведения выберите устройство через `devices` и `--output-device`, если системный выход не подходит.

Результаты сетевых проверок зависят от доступности сервиса, прав аккаунта и версии протокола. Для серверного ASR отдельно нужны токен и `YANDEX_ASR_KEY`; локальный ASR их не использует.
