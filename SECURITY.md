# Сообщения о проблемах

Не публикуйте OAuth-токены, ключи ASR, полный сетевой дамп, записи чужой речи и персональные данные в issue или pull request. Для обычной ошибки достаточно версии Python, команды без секретов, типа исключения и минимального примера с вымышленными данными.

Если сообщение содержит секреты или описание уязвимости с последствиями для других пользователей, используйте доступный приватный канал связи из [профиля автора](https://github.com/Iversat). Публичные issue не являются приватным каналом. Срок ответа и отдельная программа вознаграждений не обещаются.

Тесты используют значения `local-test-token` и `local-test-key`: это фиктивные строки, не учётные данные сервисов. Они не дают доступа к Яндексу.
