# Безопасность

Я прошу не публиковать токены, ключи, cookies, записи чужой речи и персональные данные в Issues или Pull Requests. Для обычной ошибки достаточно команды без секретов, версии Python и текста ошибки.

## Токены

`yandex_login.py` сохраняет токен в `.env` открытым текстом. Файл исключён из Git; не добавляйте его в архивы и публичные сообщения. Если папка синхронизируется с облаком, учитывайте, что `.env` тоже может синхронизироваться.

Для хранения через системный keyring я предусмотрел `auth login` и `auth import`. `.env` и окружение процесса имеют приоритет над keyring. `auth logout` удаляет токен из keyring, но не из `.env`; отозвать доступ можно в настройках Яндекс ID.

## Голос

Whisper и Vosk распознают речь локально. В `voice` после триггера распознанная команда передаётся Яндексу. `--follow-up` открывает окно для следующих команд без повторного триггера. Записи микрофона не сохраняются; `--output` сохраняет только аудиоответы. При `--backend yandex` исходное аудио отправляется Яндексу для распознавания.

## Связаться со мной

Об обычной ошибке напишите в [Issues](https://github.com/Iversat/Alice-Client/issues). Если сообщение содержит чувствительные сведения, сначала свяжитесь со мной через доступные контакты в [моём профиле](https://github.com/Iversat), не размещая секреты в публичном обсуждении.
